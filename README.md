# Lura Studio V4

Updated concept simulator for the Lura LED hat idea.

## New in this version
- Before / After side-by-side comparison mode.
- Simple % mode and Real units mode.
- Real units mode shows approximate RGB color, lumens, centimeters, degrees, and pulse frequency.
- Black cap styling closer to the supplied reference image.
- Softer, more realistic downward face lighting.
- Wearer-view outward mode with a visible brim silhouette and soft under-brim light spill.
- Mobile layout keeps the camera preview smaller and sticky so sliders remain easier to use.

## Run locally
Use VS Code Live Server or:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Camera access works best on localhost or HTTPS.
